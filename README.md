QR Code Generator
A fast, lightweight, and responsive web application for generating customized QR codes, built using HTML5, CSS3, and Vanilla JavaScript.

Features
Instant QR Generation: Create QR codes instantly from text input or web URLs.

Style Customization: Adjust QR code dimensions from 150px to 400px and customize foreground and background colors.

Download Capability: Export generated QR codes directly as high-resolution PNG images.

History Management: Automatically save and retrieve recent QR codes using browser localStorage.

Theme Support: Switch between Dark and Light mode interface themes.

Clipboard Actions: Copy input text or generated QR images directly to the clipboard.

Keyboard Navigation: Trigger generation instantly using the Enter key.

Getting Started
Prerequisites
No build tools or external dependencies are required. The application runs directly in any modern web browser.

Installation and Setup
Clone the repository to your local machine:

Bash
git clone https://github.com/YOUR_USERNAME/qr-code-generator.git
Navigate to the project directory:

Bash
cd qr-code-generator
Open index.html in your preferred browser to run the application.
